# Games

Games written in Python with kaypy, running in your browser. Each one is a
single HTML file — the whole game, the sprites, and Python itself — built with
`kaypy web`.

## Flappy Bean

Space or click to flap. Don't touch anything.

[Play Flappy Bean →](../static/games/flappy_bean/)

The pipes are plain rectangles, so there is no artwork to find and every
number that shapes the game — the gap, the gravity, how hard a flap pushes —
sits in one block at the top, ready to be argued about.

## Dino Quest

Arrows or WASD to walk, **Z** for the sword, **space** to talk to a villager.

[Play Dino Quest →](../static/games/top_down_game/)

A top-down adventure across two villages, where the villagers ask you
questions. Answer one right and it never comes back; answer it wrong and the
same villager asks you again next time. The questions come from a JSON file on
the web, so the same game can be a different quiz every week — which is the
point of it. Enter the quiz code at the start, or leave the box empty for the
practice questions.

## Send in a game

If you have built something with kaypy, it can go on this page.

**What to send:** a link to the game already playable on the web — the page,
not the source. `kaypy web game.py` makes the one file you need; upload it to
itch.io, GitHub Pages, Netlify, or anywhere that serves a page.

**What gets put up:** anything that runs, is yours, and is fit for a
classroom. Games get played before they go up, so allow a few days.

**If you are a student:** ask your teacher first.
