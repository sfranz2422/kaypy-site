Games

Games written in Python with kaypy, running in your browser. Each one is a single HTML file — the whole game, the sprites, and Python itself — built with kaypy web.

Flappy Bean

Space or click to flap. Don't touch anything.

Play Flappy Bean →

The pipes are plain rectangles, so there is no artwork to find and every number that shapes the game — the gap, the gravity, how hard a flap pushes — sits in one block at the top, ready to be argued about.

Turn-Based Battle

Up and down to move the cursor, space to choose, x to go back. Click the picture first so the keys reach it.

Play Turn-Based Battle →

The knight on the right, three monsters on the left, and the four commands every old role-playing game had: Attack, Magic, Item, Run. Everyone takes a turn in speed order, fastest first, and the round repeats until one side is finished.

A proof of concept rather than a whole game — one battle, win or lose. It is here because of how it is written: there is not a single game object in it. Every fighter is a dictionary and the screen is drawn from them each frame. How it was built →

Dungeon Dash

Arrow keys to run, space to jump, x to dash.

Play Dungeon Dash →

Five rooms and a boss. Collect every coin in a room and the door opens, and each door hands you a new move: a double jump, then a dash, then a wall jump. The next room always has one coin you cannot reach without the move you were just given, so the thing you have learned is the thing you immediately need.

The levels are pictures. Each one is twenty characters wide and thirteen tall, and a # is a wall, an o is a coin, a g is a goblin. Moving a coin means moving an o. How it was built, step by step →

Dino Quest

Arrows or WASD to walk, Z for the sword, space to talk to a villager.

Play Dino Quest →

A top-down adventure across two villages, where the villagers ask you questions. Answer one right and it never comes back; answer it wrong and the same villager asks you again next time. The questions come from a JSON file on the web, so the same game can be a different quiz every week — which is the point of it. Enter the quiz code at the start, or leave the box empty for the practice questions.

Send in a game

If you have built something with kaypy, it can go on this page.

What to send: a link to the game already playable on the web — the page, not the source. kaypy web game.py makes the one file you need; upload it to itch.io, GitHub Pages, Netlify, or anywhere that serves a page.

What gets put up: anything that runs, is yours, and is fit for a classroom. Games get played before they go up, so allow a few days.

If you are a student: ask your teacher first.
